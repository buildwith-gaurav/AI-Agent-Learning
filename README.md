# Project 1 - AI Chatbot with Conversation Memory

An AI chatbot built using FastAPI and Gemini API.

## Features

- FastAPI REST API
- Gemini API integration
- Conversation memory
- Pydantic validation
- Environment variable based API key
- Swagger API testing

## Tech Stack

- Python
- FastAPI
- Gemini API
- Pydantic
- python-dotenv

## API

POST /chat
